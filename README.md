# ChopLife App

Project management artifacts for **ChopLife**, an AI-powered food delivery app for the African market, launching in Nigeria, Ghana and Cameroon. Planned delivery: July 2026 to June 2027. Built as a Week 2 capstone simulation in the Women Techsters Bootcamp (Cohort 5.1, Technical Project Management track). I led the project as Project Manager and Team Lead.

## The product

ChopLife connects busy professionals and 9-5 workers to local and exotic restaurants, with delivery to the door. What sets it apart:

- AI meal suggestions based on what you are craving
- Budget-based meal recommendations
- Group ordering with bill splitting
- AI vendor ranking driven by customer reviews
- Inter-state ordering
- Affordable and fast delivery

15 features are in scope, including login, menu, cart, checkout, payment gateway, order tracking, rider assignment, ratings and reviews, notifications and customer support.

## Documents

All files are in the `documents/` folder. Readable Markdown versions of the Project Charter and Risk Log are in `documents/markdown/`, so you can read them on GitHub without downloading anything.

| Document | What it covers |
|---|---|
| Project Charter | Goals, scope, target users, stakeholders, timeline, budget, approval |
| Work Breakdown Structure | 5 phases, all 15 features broken into sub-tasks with owners |
| Gantt Chart | Weekly timeline, milestone tracker and sprint plan |
| Risk Log | 12 risks with likelihood, impact, mitigation and owner |
| User Stories | 15 stories with acceptance criteria, priority and story points |
| Project Plan | Execution approach, resources, tools, quality, change and communication plans |
| Master Project Plan (spreadsheet) | 9 tabs: overview, Gantt, WBS, sprint plan, milestones, risks, budget, stakeholders, user stories |
